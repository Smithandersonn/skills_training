## ✨ Funcionalidades
- ⏱️ Timer Pomodoro tradicional (25/5)
- 🎛️ Modo customizável (ajuste seus tempos)
- 🎨 Troca de temas de cores (4 opções)
- ⏯️ Controles play/pause

## 🚀 Como usar
1. Clone o repositório ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador
3. Escolha entre modo padrão ou custom
4. Clique em **START** para iniciar
5. Para trocar as cores, clique no botão colorido no canto superior direito

## 📚 Aprendizados
- Manipulação do DOM com JavaScript
- Controle de tempo com `setInterval()` e `clearInterval()`
- Event Listeners para interatividade
- CSS Flexbox para layout responsivo
- Variáveis CSS para gerenciamento de temas

## 🛠️ Tecnologias
- **HTML5** - Estrutura da página
- **CSS3** - Estilização (Flexbox, Variáveis CSS)
- **JavaScript (ES6+)** - Lógica e interatividade
